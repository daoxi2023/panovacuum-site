# 帕诺真空主页审计与优化

> 更新：2026-10-28 已按用户明确授权发布；原文记录本地审计阶段，当前上线与回滚信息见 RELEASE_2026-10-28.md。

日期：2026-10-28。范围：中英文主页、共用导航和页脚。本次交付为本地源码与预览，未推送或发布。

## 设计依据与最终方向

参考 https://ysvacuum.com/。通过现成国内 P330 主机，以不使用代理的 HTTP 请求读取官网 HTML、主样式、响应式样式与首张轮播图；未更改主机或网络配置。参考结构：白底横向导航、通栏图片、居中标题、四列图卡、左文右图公司介绍、浅色页脚。原站使用浅蓝色，帕诺使用自己的真实照片和独立实现。

用户否决第一版偏灰的鼠尾草绿。最终改为白色为主、薄荷翡翠绿强调：按钮 #00866B、正文标题 #142E2B、辅助文字 #4A625B、浅背景 #F0FAF6。白字按钮的静态颜色对比约 4.54:1。没有复制参考站图片、文案或整站代码，也没有照搬其纯图片轮播、搜索或留言后台。

参考站部分后续资源连接失败，因此本次参考的是已经取得的布局、样式和首图，未进行整站逐像素比对。

## 发现与处理

| 问题 | 处理与结果 |
| --- | --- |
| 主图使用浮动布局，落入设备数据区，挤压数值 | 改为独立通栏首屏；图片与后续区块隔离 |
| 手机端隐藏主图 | 手机保留主图，调整浅色遮罩与对比度 |
| 原有深蓝视觉与用户要求不一致；初版绿色发灰 | 白底、清爽薄荷强调色，减轻图像遮罩 |
| 页面区块全部使用相似卡片 | 制造能力四图卡，公司介绍图文两列，质量流程、行业和合作步骤采用不同层次 |
| 导航在较窄屏幕挤压 | 桌面横排、窄屏折叠菜单；点击项目及 Escape 后收起 |
| 主标题和设备单位断行不自然 | 中文按语意分两段；数值及单位保持完整分组 |
| 首屏图片延迟加载、图片缺乏尺寸 | 首图高优先级加载，其余图片延迟加载；补充尺寸 |
| 中文文档固定声明英文 | 构建后按路径修正静态语言；客户端切换同步文档语言 |
| 空微信二维码占位、电话不可直接点击 | 移除假占位，电话转为可拨链接 |
| 现有询价表单尚未接通 | 不伪造提交成功；保留说明，首页提供直接邮件发送图纸入口 |

## 改动文件

- app/[locale]/page.tsx：主页布局与图片、标题、数值分组。
- app/home.css：隔离到主页的布局和响应式样式。
- app/globals.css：共用色彩、导航、页脚、键盘焦点、减少动画偏好。
- app/components/header.tsx：导航、手机交互、电话、客户端语言同步。
- app/components/footer.tsx：去除空二维码占位、增加电话链接。
- app/layout.tsx：仅在根 HTML 上允许预期的静态语言属性差异。
- scripts/normalize-hreflang.mjs：保留语言链接规范化，同时修正静态页面语言。

## 验证证据

- Next.js 生产构建、静态导出、类型检查通过；生成 20 个静态页面。
- 既有 pnpm 启动包装器尝试重新安装依赖，因此直接调用已安装的 Next.js 构建入口与原有构建后脚本；没有安装、升级依赖。
- 独立审查：原有区块锚点及图片路径无删除；中英文主页各 40 个链接的目标文件及锚点有效，各 1 个主标题，12 张图片文件存在。
- 浏览器检查：中文、英文分别在 320、375、768、1024、1440、1920 像素宽度下均无横向溢出；手机主图保持可见。
- 实际点击手机菜单展开、区块链接跳转及自动收起通过。
- 实际通过语言按钮双向切换，页面地址和文档语言均正确。
- 主页图片、脚本、样式均来自本地站点；未添加境外字体或素材服务依赖。
- 首屏图片优先加载，未使用延迟加载。
- 独立代码审查未发现功能保留、安全或布局结构阻断项。
