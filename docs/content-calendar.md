# 内容更新节奏与编辑日历（博客 freshness 信号）

> 目的：让博客保持「持续更新」的站点信号，同时守住合规红线。
> 节奏承诺（对搜索引擎与读者都成立）：**每月至少 1 篇双语技术文章**，冲刺期 1-2 篇。

## 一、更新节奏
- 常态：每月 1 篇双语技术文（中英同日发布，同日更新 sitemap / llms.txt）。
- 素材事件（进博会、新设备到厂、首触节点）当月追加 1 篇短图文。
- 法定 / 行业节点（认证推进节点、融资可披露节点）按事实发布，不编造。

## 二、发布流程（署名制）
1. 选题：从选题池取 1 条，排入编辑日历。
2. 起草：技术类由工艺 / 质检角色署名；商务类由周游署名。
3. 合规审：对照红线清单（无 ISO 洁净室表述、无伪造认证、能力只写台账内、不写行业领先、不承诺整机）。
4. 老板终审：发布前必须过老板确认（内容对外即公司口径）。
5. 发布：双语同日上线，回填日期、署名、链接到编辑日历。

## 三、署名规则
- 技术文章：署名「帕诺工艺团队 / PANO Process Team」+ 角色 + 企业邮箱。
- 商务 / 流程文章：署名「周游 / Zhou You」+ 角色 + 邮箱。
- 每篇文章正文页显示作者名、角色、联系方式（已随 E-E-A-T 人员信号上线）。
